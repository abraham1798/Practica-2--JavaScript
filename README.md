# Práctica 2 - JavaScript

Práctica del curso Ambiente Web Cliente Servidor.

## Descripción

Este proyecto contiene una serie de ejercicios básicos desarrollados con HTML, CSS y JavaScript.

## Ejercicios

- Cálculo de cargas sociales e impuesto sobre la renta.
- Manipulación del DOM.
- Estructuras condicionales.
- Manipulación de arreglos.

## Tecnologías

- HTML5
- CSS3
- JavaScript
